Student instructions

How to use this course pack

Before arrival, complete the assigned Lecture 1–8 and Home Reading preparation (at least 20 hours in total). Use each reading guide’s questions to check the key terms and concepts. Note any unclear steps for class.

Assessment

Tutorial credit: each submitted Tutorial with a substantive attempt earns 1 percentage point, regardless of correctness. No credit is given for a missing or blank submission or copied question text only. All eight count; no scores are dropped. Tutorials 9–10 are optional and carry no submission credit.

Each project is marked out of 100 and contributes its score × 0.16 to the course total. Project 2 retains up to 10 optional bonus marks, capped at a project score of 100. The Practice Exam is preparation only and does not count towards the course grade.

How to study

A simple weekly routine

01 · BEFORE CLASS

Preview the topic

Read the assigned slides and textbook sections. Try the Home Reading understanding questions before class; record any question you cannot yet answer.

02 · DURING CLASS

Build the model

Use the Lecture PDF to follow the assumptions, modelling steps, plots and engineering checks. Add your own notes beside the worked examples.

03 · AFTER CLASS

Practise independently

Attempt the selected Tutorial parts before the practice session. Return to the lecture and textbook when a step is unclear, and bring unresolved questions to class.

04 · APPLY

Use engineering evidence

Start each Project early. Use your calculations, MATLAB results and physical checks to support the engineering decision requested in the brief.

Teaching sequence

Course route

Classes 1–5 · Project 1

Physical modelling, transfer functions, time response and frequency response.

Lectures 6–8 · Project 2

Lecture 6 uses two sessions: physical modelling, then state space. Lectures 7–8 cover feedback and stability.

Classes 9–10 · Optional

Root locus and P, PI and PID control.
