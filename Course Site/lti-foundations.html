01 / LTI FOUNDATIONS

LTI state model

Linear: zero-state responses obey superposition. Time invariant: shifting the input shifts the response by the same amount. Use deviation variables about a nonzero operating point.

ẋ = Ax + Bu
y = Cx + Du
SymbolMeaningDimensions
xStaten × 1
u, yInput, outputq × 1, r × 1
A, B, C, DConstant matricesn × n, n × q, r × n, r × q
x(t) = eAtx0 + ∫0t eA(t−τ)Bu(τ) dτ

The first term is the zero-input response; the integral is the zero-state response. Here we use finite-dimensional, continuous-time models.

Superposition and time shift
a u1 + b u2 → a y1 + b y2
u(t−t0) → y(t−t0)

Zero initial state; shift the initial-state convention consistently.

02 / LTI FOUNDATIONS

ODE → transfer function

m ẍ + b ẋ + kx = f(t)

Let x(0)=x0 and ẋ(0)=v0. Taking the Laplace transform:

m[s2X − sx0 − v0] + b[sX − x0] + kX = F
X(s) = F(s)ms2 + bs + k + (ms+b)x0 + mv0ms2 + bs + k

Set the initial conditions to zero to define the force-to-displacement transfer function:

G(s) = X(s)F(s) = 1ms2 + bs + k
State form
ẋ = v
v̇ = −(k/m)x − (b/m)v + f/m,   y = x

Displacement and velocity are two independent states.

03 / LTI FOUNDATIONS

Order and hidden modes

State order: the number of independent states. Transfer-function order: the degree of the reduced SISO denominator. These agree for a minimal realization.

G(s) = C(sI − A)−1B + D
det(sI − A) = 0

The eigenvalues of A describe internal modes. A mode may disappear from a transfer function if the input cannot excite it or the output cannot observe it.

ẋ1 = −x1 + u,   ẋ2 = x2,   y = x1
G(s) = 1/(s+1)

Internal order: 2. Visible order: 1. The hidden state grows when x2(0) ≠ 0, although G(s) is stable.

04 / LTI FOUNDATIONS

Poles → time response

Why exponentials?

Start with the free first-order equation and take its Laplace transform:

ẋ = px,   x(0)=x0
sX(s) − x0 = pX(s)
X(s) = x0s−p
x(t) = x0ept

The pole p gives the exponential rate. For a state model, the roots of det(sI−A)=0 play the same role. Partial fractions combine these terms into the full response:

Term in the Laplace domainTime-domain term
1/(s−p)ept
Conjugate poles σ ± jωeσt[c1 cos(ωt) + c2 sin(ωt)]
1/(s−p)ℓtℓ−1ept/(ℓ−1)!

Real part: decay or growth. Imaginary part: oscillation frequency. Initial conditions, input and modal weights determine the amplitudes.

Stability

Internal asymptotic stability: every eigenvalue of A has negative real part. BIBO stability of a proper rational transfer function: every pole of the reduced function has negative real part.

Repeated eigenvalues and input poles

Repeated eigenvalues produce polynomial factors only when the associated Jordan blocks require them. A step input adds 1/s to Y(s)=G(s)U(s); this is an input pole, not an extra system pole.

05 / LTI FOUNDATIONS

Series, parallel and feedback

ConnectionTransfer function
SeriesG = G1G2
ParallelG = G1 + G2
Negative feedbackT = G/(1+GH)

Form the connected model, then simplify and find its poles.

1s+1 + 2s+1 = 3s+1
s+2s+1 × 1s+2 = 1s+1

Parallel branches and cancellations need not increase the visible order.

G(s) = 1s(s+1),   H=1
T(s) = KG1+KG = Ks2+s+K

Feedback changes the characteristic equation. An unstable cancellation may hide an unstable internal mode.

Try a first-order plant

G(s) = 1/(s+1),   T(s) = K/(s+1+K)

Blue ×: plant pole. Teal ×: reference-to-output pole. At K=0, T(s)=0; the plant still has its natural mode.
