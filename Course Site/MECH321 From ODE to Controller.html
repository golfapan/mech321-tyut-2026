From ODE to Controller

One argument runs through the eight core lectures. Lectures 9 and 10 extend it as optional studies. A machine becomes a differential equation. The Laplace transform turns that equation into algebra, carrying the initial conditions with it. Lecture 3 separates the response into the part driven by stored energy and the part driven by the input. The course follows the input part, divides the input out, and is left with the plant itself: G(s). The plant is then read in time and in frequency, and only after that is a loop closed around it. Lecture 6 takes the same modelling chain into the electrical, electromechanical and thermal domains, and introduces state space alongside the transfer function: another representation of the same model, retaining internal states and their initial values.

The chain 整条主线

Every arrow is an operation you perform, labelled with the job it does, and with the lecture that teaches it. The chain starts in five physical domains: Lecture 1 opens four of them and Lecture 6 returns with the electrical, electromechanical and thermal detail. The amber path is the main transfer-function route. The grey response branch keeps the initial-condition contribution; the dashed state-space branch introduces a parallel representation in Lecture 6.

What each tool is for 每个工具到底在做什么

Five operations carry the whole course. Knowing which one you are holding tells you where you are standing on the chain.

Forward transform

L2 ODE → algebra
m ẍ + b ẋ + k x = u(t) → (ms²+bs+k)X(s) = U(s) + ICs

Job: make the equation solvable. Each derivative becomes a multiplication by s, so calculus turns into arithmetic, and the initial conditions travel with it as extra terms. The physics is unchanged. Only the form of the equation changes.

Divide by U(s)

L3 algebra → plant
X(s) = G(s)·U(s) → G(s) = X(s)/U(s)

Job: separate the machine from the test. The division removes whichever input you applied and leaves the selected input-output description of the plant. This transfer-function route assumes zero initial conditions. The parallel state-space representation introduced in Lecture 6 can retain a nonzero initial state.

Inverse transform

L2 s-answer → curve
X(s) = 5/[s(s²+2s+5)] → x(t)

Job: get the answer back into time. The algebra is done in s. The answer is needed in t: how far it moves, how long it rings. You do the full inversion only a few times, for the standard first- and second-order forms. After that you read overshoot and settling straight off the pole locations.

Partial fractions

L2A in service of the inverse
N(s)/D(s) → A/(s−p₁) + B/(s−p₂) + …

Job: split the expression into terms the table recognises. The technique carries no physics of its own and is used nowhere else in the course. It exists so the inverse transform can be done term by term, which is also why the frequency branch never needs it.

Set s = jω

L5 plant → measured curve
G(s) → G(jω) = |G(jω)| ∠G(jω)

Job: find what the plant does to a sine you can actually apply. On the imaginary axis G(s) becomes one magnitude and one phase per frequency. No inversion and no partial fractions. This is the reading you can obtain directly from a rig, so model validation is done here.

Which part of the response you keep 两个分支

The transformed equation has two sources on its right-hand side. Which one you keep decides which half of the subject you are in.

Branch A · set aside L3

Zero-input response

u(t) = 0,  (x₀, v₀) ≠ (0, 0)

Driven by stored energy: a released spring, a coasting rotor. It cannot be written as G(s)·U(s), because the transfer-function calculation sets the initial state to zero. Lecture 2 carries the initial-condition terms into the algebra; Lecture 3 writes this contribution out as X₂(s) = [(ms+b)x₀ + mv₀] / D(s) and then sets it aside. Lecture 4 connects its poles to free-decay modes, and Project 1 uses a fixed-floor release test. Lecture 6 retains initial states explicitly in state space.

Branch B · the road L3

Zero-state response

x₀ = v₀ = 0,  u(t) arbitrary

Driven by the input. This is the branch that supports a transfer function, poles and zeros, step response, Bode diagram, feedback and every controller. A later lecture saying "assume zero initial conditions" is pointing back at this choice.

State space alongside the transfer function L6 同一模型的两种表示

Lecture 6, especially slides 19–26, develops these as parallel views of the same physical model. The dashed branch is a complete representation example, not a second control-design route.

State space rewrites the governing differential equations as a set of first-order equations. The worked example begins from a given two-state model so the lecture can focus on the representation. It then relates the abstract coordinates to physical motor states such as armature current and shaft speed. Two independent states give a two-dimensional state vector and a 2 × 2 A matrix; state space is not restricted to two states.

Its advantages are explicit internal variables, initial states that need not be zero, and a convenient representation for multiple inputs and outputs. Under zero initial conditions it also gives the transfer function. State feedback, observers and multi-input/multi-output control build on this representation in later courses; we do not develop those methods here.

What frequency response shows directly 频域更直接地展示哪些信息

A step response answers one question: what happens after this particular event. A frequency sweep answers a different one: which inputs this plant is vulnerable to, and how much room the loop has before it becomes unstable. The comparison is between a unit-step trace and a sinusoidal frequency sweep, not a claim that the two domains contain mutually exclusive information. At one frequency, sinusoidal time records give gain from the amplitude ratio and phase from the time offset. A sweep repeats that measurement across frequencies.
