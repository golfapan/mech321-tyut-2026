LECTURE 4 · HIGHER-ORDER RESPONSE AS A SUM OF MODES

Why first- and second-order systems?

Linear time-invariant systems · 线性时不变系统

A MODEL CLASS, NOT A CLAIM ABOUT EVERY REAL SYSTEM

One model, many inputs.

Linear · 线性

With zero initial state, scaling and adding inputs scales and adds their outputs.

u1 → y1, u2 → y2
a u1 + b u2 → a y1 + b y2

For physical systems with a nonzero operating point, use deviations from that operating point.

Time invariant · 时不变

Delay the same input and the response delays by the same amount. The model parameters do not depend explicitly on clock time.

u(t − t0) → y(t − t0)The initial-state convention must shift consistently.
The common language
ẋ = Ax + Bu,   y = Cx + Du
G(s) = C(sI − A)−1B + D

The state model retains initial conditions. The transfer function describes a selected zero-state input–output path.

Constant rate versus proportional rate

Constant rate: ẋ = −a gives x = x0 − at.

This can be an LTI integrator ẋ = u driven by the constant input u = −a. It does not by itself prove nonlinearity.

Proportional rate: ẋ = p x gives x = x0 ept.

If written as Ṅ = −λN, then p = −λ. For decay, λ > 0 and p < 0; τ = 1/λ. The sign changes behaviour, not whether a well-posed linear ODE has a solution.

Ask first: what is the input, what is the output, and about which operating condition is the model written?

FINITE-DIMENSIONAL LTI MODELS WITH REAL COEFFICIENTS

Higher order exists. Its modes use familiar building blocks.

After normalising the leading coefficient to one, the real denominator factors as:

D(s) = ∏(s − pi) ∏[(s − σj)2 + ωj2]

A real pole

p → ept

p < 0: decays.
p > 0: grows.
p = 0: a constant free mode.

A first-order decay is described by one time constant.

A conjugate pair

σ ± jω
→ eσt(B cos ωt + C sin ωt)

The real part sets the envelope. The imaginary part sets the oscillation frequency.

A repeated pole

1/(s − p)2 → t ept

Repeated factors can add polynomial time factors. They are not a new third-order type of oscillation.

Factorisation is exact. Keeping only a few factors is an approximation.

A cubic may have three real poles, or one real pole and one complex pair. A fourth-order model can contain several combinations. First- and second-order factors describe the modes; they do not necessarily represent separate physical components.

Natural modes versus input poles

The system poles describe natural dynamics. To obtain a zero-state response, use Y(s) = G(s)U(s).

A unit step adds 1/s to Y(s). That input pole at zero is not a new system pole.

Two stability questions

Internal asymptotic stability requires every eigenvalue of A to have negative real part. A proper rational transfer function is bounded-input, bounded-output (BIBO) stable when its actual poles are strictly in the left half-plane.

Eigenvalues and transfer-function poles coincide for a minimal realization. A simple integrator has a constant free state but is not BIBO stable: a bounded step produces a ramp.

A three-state system need not have a “new third-order response shape”. Can you identify its real modes and conjugate pairs?

MODAL SUPERPOSITION DOES NOT MEAN CONNECTIONS LEAVE POLES UNCHANGED

Series, parallel and feedback do different things.

Series · 串联

G = G1G2
1/(s + 1) × 1/(s + 2)
= 1/[(s + 1)(s + 2)]

The output of one block drives the next. Pole–zero cancellations across blocks may reduce the input–output order.

Parallel · 并联

G = G1 + G2
1/(s + 1) + 1/(s + 2)
= (2s + 3)/[(s + 1)(s + 2)]

Both branches receive the input; their outputs add. The numerator and zeros change.

Identical branches: 1/(s+1) + 1/(s+1) = 2/(s+1). The minimal transfer-function order stays one.

Negative feedback · 反馈

T = KG/(1 + KG)
G = 1/(s + 1)
T = K/(s + 1 + K)

The closed-loop characteristic equation changes. The pole moves from −1 to −(1 + K).

Blue ×: open-loop plant pole. Teal ×: closed-loop reference-to-output pole for K > 0. At K = 0, this input–output transfer is zero while the disconnected plant still has its natural mode.

What “superposition of modes” means

For each resulting LTI model, partial fractions express a proper response as a sum of exponential or decaying sinusoidal terms, with extra time factors for repeated poles. The input also matters. These are modes, not necessarily integer-multiple harmonics.

Series or parallel connections can have nonminimal realizations and cancellations. Feedback generally moves poles. Do not reuse the original pole set without deriving the connected model.

Which denominator should you inspect: the plant’s denominator or the actual closed-loop characteristic equation?

CHECK THE MODEL CLASS AND THE APPROXIMATION SEPARATELY

When should we change the method?

Still LTI

Important extra modes

If omitted poles affect the response or control bandwidth, keep a higher-order model. LTI analysis still applies; the low-order approximation has failed.

LTI, but not a finite rational model

Significant delay

G(s)e−sT

A fixed delay is linear and time invariant. Keep its phase effect; a first-/second-order fit may be inadequate.

Different time description

Sampling and digital control

A sampled model may be discrete-time LTI. Use z-plane poles and the unit-circle criterion; include sample/hold and delay effects.

Nonlinear behaviour

Saturation, friction, large motion

Hard actuator limits, backlash, dead zones and large-angle geometry can invalidate superposition. Use an appropriate nonlinear or piecewise model and simulate the actual limits.

Time-varying parameters

The operating conditions move

When mass, resistance or coefficients change significantly with time, one constant A or G may no longer represent the experiment. Use a time-varying model or validated models for several conditions.

Input–output view is insufficient

Hidden internal modes

A cancelled or unobserved mode can disappear from one transfer function. Check the internal state model, especially when unstable pole cancellation or feedback interconnection is involved.

Use linearisation carefully · 局部线性化
ẋ = f(x,u)
δẋ ≈ A δx + B δuA = ∂f/∂x, B = ∂f/∂u, evaluated at an equilibrium.

A pendulum can use sin θ ≈ θ for small angular deviations near the chosen equilibrium. A large swing requires the nonlinear equation.

For a smooth autonomous system near an equilibrium: all linearised eigenvalues strictly left imply local asymptotic stability; a positive real part implies instability.

Eigenvalues on the imaginary axis make this test inconclusive. Local linearisation alone cannot establish global behaviour, limit cycles or chaotic motion.

Use the simplest model that answers the question and survives validation.

A stable linear model can still be an inaccurate model. When experiment or simulation disagrees, check inputs, initial conditions, units, missing dynamics and nonlinear limits before drawing a design conclusion.
