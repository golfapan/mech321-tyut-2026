Project 1 MATLAB starter files

Keep this MATLAB folder beside the project question document.
Requires MATLAB R2020a or later. No additional toolbox is required.
Open the required .m file in MATLAB and click Run.
Each script saves its plots and data in the Plots folder beside the script.

Project01_01_Input.m       Stage 1: prescribed floor input.
Project01_02_Response.m    Stage 4.2: floor-bump responses.
Project01_03_Frequency.m   Stage 5: Bode magnitude in dB.
Project01_04_FreeDecay.m   Stage 4.1: fixed-floor release.

Use the project questions for the required changes and submissions.
In the free-decay starter, replace the wn and zeta NaN placeholders
with your derived expressions. Extend the design arrays as requested.
